## Start here

- Explore the [Overview](/overview/intro) for the mission, values, and code of conduct.
- Jump into [Discord](/discord/etiquette) to learn the guild communication flow.
- Review [Membership](/membership/join-the-guild) to understand how to join and grow.
- Reference [DAO Operations](/dao-operations) for proposals, roles, and tokens.

## Run the site locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to browse the handbook.

## What's inside

- RaidGuild typography (Mazius Display + EB Garamond) and the Moloch palette.
- Ordered navigation across every handbook section and a per-page table of contents.
- Escrow and DAO walkthroughs with screenshots carried over from the legacy docs.
